# Roadmap

This is a public direction-of-travel document, not a promise of release dates.

## Near term

- Keep the registry and application consumer-contract checks blocking and reproducible.
- Expand validated ANSYS Fluent journal rules without executing user content.
- Improve cluster-profile documentation and contributor examples.

## Later

- Add more declarative scheduler and cluster profiles through reviewed contributions.
- Publish versioned compatibility guidance for new HPC Client GUI releases.
- Add contributor tooling for inspecting plugin payloads before opening a pull request.

## Proposals

Open an issue with the `enhancement` label and include the user problem, the
declarative data needed, and authoritative documentation for any site-specific
facts.
