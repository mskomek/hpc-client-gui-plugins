# NERSC Perlmutter cluster profile

This is an independent community provider for HPC Client GUI and is not
endorsed by NERSC. An active NERSC account and current authentication setup are
required. NERSC `sshproxy` is a manual prerequisite; this plugin never runs it.

Perlmutter Scratch uses the documented `/pscratch/sd/{user_first}/{user}`
layout. Scratch data may be purged after eight weeks without access. Quota is
opt-in and uses the application's fixed `nersc-showquota-json` backend.

Last verified: 2026-08-31. Host, authentication, allocation, quota, and
retention policies can change; consult the linked official documentation.
