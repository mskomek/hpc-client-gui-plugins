# Pawsey Setonix cluster profile

Independent community provider for HPC Client GUI; not endorsed by Pawsey.
An active Pawsey account and Setonix allocation are required. Project paths
remain unresolved until the user supplies a project identifier.

The data-mover host is descriptive only. This profile does not automatically
reroute transfers. Quota uses the application-owned parser for the documented
`pawseyAccountBalance -s` filesystem summary and reports byte and file usage.

Last verified: 2026-08-31.
