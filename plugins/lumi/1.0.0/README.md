# LUMI cluster profile

This is an independent community provider for HPC Client GUI and is not
endorsed by LUMI or CSC. An active LUMI project and SSH authentication are
required. Project-aware storage stays unresolved until the user supplies a
project identifier.

The profile describes Home, Project, Scratch, and Flash paths from the current
LUMI documentation. Quota uses the application's fixed `lumi-quota` backend;
allocation monitoring is intentionally not included.

Last verified: 2026-08-31. Check official LUMI documentation for current
partitions, account policy, storage limits, and retention notices.
