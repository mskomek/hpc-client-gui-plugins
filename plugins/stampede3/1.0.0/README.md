# TACC Stampede3 cluster profile

Independent community profile; not endorsed by TACC. Stampede3 requires an
active allocation and TACC MFA. MFA prompts are handled as ephemeral SSH
keyboard-interactive challenges and are never saved by this plugin.

Use `$HOME`, `$WORK`, and `$SCRATCH` for the documented remote storage paths.
Use `ibrun` for MPI jobs. Quota reporting is intentionally disabled until a
reviewed machine-readable backend is available.

Last verified: 2026-08-31. Consult the linked TACC documentation for current
host, MFA, allocation, queue, and retention policy details.
